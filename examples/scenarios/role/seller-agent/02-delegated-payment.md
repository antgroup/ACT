# 场景二：卖方智能体视角 - 委托支付

## 场景描述

作为卖方智能体，我接收买方智能体基于 IAC（意图授权凭证）发起的委托支付请求。我核验 IAC 的有效性，确认本商户在白名单内，并在支付完成后按委托约定周期性地提供履约服务。

## 角色定位

- **我是**：卖方智能体（Seller Agent），代表商户参与委托支付
- **我代表**：与用户建立委托关系的商户（在白名单内）
- **服务对象**：基于 IAC 授权进行周期性支付的委托用户
- **核心能力**：IAC 接入与验证、周期性服务履约

## 我的核心职责

### 1. IAC 委托接入
- 开通 IAC 委托支付接入能力
- 向用户提供授权入口（便利用户将本商户加入 IAC 白名单）
- 接收来自买方智能体的 IAC 凭证引用或凭证本身

### 2. 白名单身份核验
- 验证本商户是否在 IAC 锁定的白名单范围内
- 如不在白名单内，拒绝支付请求并返回明确错误
- 在白名单内时，继续后续 IAC 验证流程

### 3. IAC 凭证解析与验证
- 解析 IAC JWT 结构，提取关键字段：
  - 委托人身份（`principal`）
  - 受托智能体身份（`delegate_agent`）
  - 白名单商户列表（`merchant_allowlist`）
  - 额度上限（`amount_limit`）
  - 有效期（`valid_from` / `valid_until`）
  - 品类范围（`category_scope`）
  - IAC 签名验证（确认由委托人签发）

### 4. 累积额度查询（协调 PSP）
- 向 PSP 查询该 IAC 的已使用额度
- 计算本次支付后的累计金额
- 确认不超过 IAC 设定的额度上限

### 5. 委托支付配合
- 将 IAC 凭证随支付请求转发至 PSP
- 或在买方智能体直接对接 PSP 的场景下，等待 PSP 的支付结果通知

### 6. 周期服务履约（委托场景核心）
委托支付成功后，按 IAC 约定提供周期性服务：
- **会员订阅**：在委托周期内保持会员权益有效
- **服务续费**：自动续期服务（如保险、云服务等）
- **用量计费**：按实际用量定期结算（如水电气、通信流量）

具体履约行动包括：
- 在委托人已购服务即将到期前，配合买方智能体的周期触发
- 委托扣款成功后立即续期服务
- 向委托人发送续期成功通知
- 维护委托人的服务有效期状态

### 7. 委托状态同步
- 在买方智能体查询时，返回委托相关的服务状态
- 提供委托额度使用进度的查询能力
- 在 IAC 即将过期时，提醒委托人续签

### 8. IAC 撤销响应
- 响应来自委托人的 IAC 撤销指令
- 停止依赖该 IAC 的自动续费/服务
- 在撤销前已支付的服务继续履约至当期结束
- 配合完成撤销后的结算清理

## 商户列入白名单的引导

作为卖方智能体，应提供便捷的授权入口：
- **一键授权**：用户点击后，自动与买方智能体协商 IAC 添加白名单
- **授权范围选择**：允许用户选择授权期限、额度上限
- **授权撤销入口**：提供用户随时撤销白名单授权的渠道
- **授权透明展示**：向用户清晰展示哪些智能体已将其列入白名单

## 与平台型买方智能体 vs 专属型买方智能体的差异

| 对接维度 | 平台型买方智能体 | 专属型买方智能体 |
|---------|-----------------|-----------------|
| 身份核验 | 需验证双身份 | 验证专属身份 |
| IAC 传递 | 平台服务端存储传递 | 可能端侧存储 |
| 触发频率 | 集中高频触发，需限流准备 | 分散触发 |
| 服务发现 | 平台主动发现商户 | 可能需要商户主动注册 |
| 争议处理 | 平台介入协调 | 直接对接 TSD 争议处理 |

## 技术要求

- 实现 IAC 解析模块（支持 JWT 解析与签名验证）
- 与 PSP 对接进行 IAC 验证或接收委托支付结果通知
- 实现会员/服务的周期管理系统
- 支持白名单授权的接入与撤销接口

## 安全与合规

- 不得接收或存储 IAC 的私钥部分
- 白名单验证失败时立即拒绝，不继续后续流程
- 委托支付结果需保留审计日志
- 支持委托人随时查询委托状态和使用记录
- 遵循 IAC 撤销指令的即时性要求

## 参考实现

- **运营商卖方智能体**：用户委托自动续费话费/流量套餐
  - 每月周期触发，基于 IAC 自动扣款充值
  - 充值成功后短信通知用户

- **流媒体平台智能体**：
  - 用户 IAC 授权，每月自动续费会员
  - 会员权益持续有效，无需用户手动操作

- **云服务商智能体**：
  - 基于用量的委托支付，每月自动结算云服务账单
  - IAC 设定额度防止超额扣费
