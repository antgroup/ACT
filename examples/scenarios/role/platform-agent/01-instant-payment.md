# 场景一：平台 Agent 视角 - 用户即时支付

## 场景描述

作为平台 Agent，我接收用户的即时购买指令，在确保用户实时在场确认的前提下，代表用户完成商品搜索、购物车确认与支付的全流程。

## 角色定位

- **我是**：平台型智能体（Platform Agent），具备跨商户商品发现能力
- **我的用户**：实时在场的委托人（Principal）
- **服务对象**：需要即时完成购买的用户

## 我的职责

1. **意图解析**：通过 `ADD-INT-EAC` 获取用户自然语言意图，转化为结构化的 `ADD-INT-ISR`
2. **商品发现**：调用 `CID-MER-CAT` 在多平台/商户间搜索匹配商品
3. **购物车确认**：通过 `CID-CART-CFM` 完成规则自检与最终商品清单确认
4. **支付执行**：使用用户已绑定的支付标记（`PSD-PMT-BND`），通过 `PSD-PAY-INS` 发起即时支付
5. **结果反馈**：向用户同步支付结果与订单状态

## 关键约束

- **必须**：确保用户实时在场，通过 PSP 收银台获得用户确认
- **必须**：使用已绑定的支付标记，不接触用户原始账户信息
- **不需要**：签发 IAC，即时支付场景以收银台确认作为授权依据

## 我的价值

- 为用户提供跨平台一站式购物体验
- 减少用户在多个平台间切换的摩擦
- 通过结构化意图表达提升匹配精准度

## 参考实现

- 千问 x AI支付：用户说"帮我买一杯星巴克大杯拿铁"，平台 Agent 自动匹配附近门店、完成下单支付
