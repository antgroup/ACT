# Conformance

The conformance suite is not yet available because ACT v2.1 schemas and the candidate `PSD-PAY-A402` state machine have not been published.

Current executable checks cover repository integrity and Quickstart behavior only. They do not grant ACT or Alipay product conformance. Planned suites will be separated into:

- ACT Core semantics and lifecycle;
- A402 Binding serialization, idempotency and replay prevention;
- Alipay AI Pay Profile field and API mappings;
- end-to-end sandbox evidence.
