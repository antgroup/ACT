## 💡 设计理念

### 三种支付模式通过**自然语言对话**区分

| 支付模式 | 触发关键词 | 对话示例 | 核心差异展示 |
|---------|-----------|---------|-------------|
| **即时支付** | "买"、"购买"、"现在买"、"下单"、"支付" | "帮我买iPhone 15 Pro" | 用户全程在场确认，无需IAC |
| **委托支付** | "授权"、"委托"、"自动续费"、"定期"、"开通委托" | "授权每月自动续费咖啡，不超过200元" | 预签发IAC，额度管控，智能体代付 |
| **自主支付/A2A** | "帮我安排"、"帮我规划"、"出差"、"旅游"、"整体方案" | "帮我安排下周出差上海，预算5000元" | 任务边界，A2A智能体间交易，HTTP 402，子账户 |

## 📱 使用方式

### 1. 选择角色
- 👤 **用户**：体验三种支付模式
- 🏪 **商户**：管理商品和查看订单

### 2. 用户角色对话指令

#### 💸 即时支付 (PSD-PAY-INS)
```
用户：帮我买一杯星巴克大杯拿铁
智能体：💸 即时支付确认...
用户：确认支付 → 完成支付
```
**展示重点**：ADD-INT-EAC → ADD-INT-ISR → CID-CART-CFM → PSD-PAY-INS

#### 💼 委托支付 (PSD-PAY-DEL)
```
用户：帮我授权每月自动续费，额度1000元
智能体：💼 委托支付授权设置...
       拟定的授权参数：
       - 总额度上限：1000
       - 模式：定向委托 (delegation_mode=SPECIFIED)
用户：签发委托
智能体：✅ IAC委托授权已签发！
       [生成IAC凭证JWT]

后续：
用户：用委托买iPhone
智能体：✅ 委托支付成功！
       无需您实时在场，智能体自主执行
```
**展示重点**：ADD-IAC-ISS → IAC生命周期管理 → PSD-PAY-DEL

#### 🤖 自主支付/A2A (PSD-PAY-A2A)
```
用户：帮我安排下周出差上海，预算5000元
智能体：🤖 自主支付/A2A支付任务规划...
       任务：出差行程安排（机票+酒店+用车）
       预算：5000
       专属子账户开立
       模式：委托_MODE=BOUNDED + A2A支付

用户：确认创建任务
智能体：✅ 任务已创建！

用户：开始执行
智能体：🤖 A2A自主支付执行实录
       1. 买方智能体：拆解任务（机票、酒店、用车）
       2. 服务发现：在A2A市场发现卖方智能体
       3. CID-PCA-NEG：支付能力协商
       4. HTTP 402：卖方返回支付诉求
       5. A2A支付：提交支付载荷
       6. PSP核验：验证IAC+子账户密钥签名
       7. 扣款成功：子账户扣款¥800，余额¥4200
```
**展示重点**：PSD-AGT-SUB → CID-PCA-NEG → HTTP 402 → PSD-PAY-A2A

## 🔧 通用对话指令

### 所有用户可用：
- "帮助" → 查看三种支付模式说明
- "查看商品" → 列出所有商品
- "我的订单" → 查看订单记录
- "委托状态" → 查看IAC授权和额度

### 确认指令：
- "确认支付" → 确认待执行的支付
- "签发委托" → 确认创建IAC委托
- "确认创建任务" → 确认创建A2A任务
- "开始执行" → 开始模拟A2A执行
- "取消" → 取消当前操作

### 修改参数：
- "修改额度 [金额]" → 修改委托总额度
- "修改预算 [金额]" → 修改A2A任务预算

## 🎨 界面特点

1. **全对话交互**：类似ChatGPT的聊天界面
2. **协议标签**：每条消息显示使用的ACT协议（PSD-PAY-INS / PSD-PAY-DEL / PSD-PAY-A2A）
3. **逐步引导**：智能体通过对话引导用户完成每种支付模式
4. **徽章提示**：显示当前使用的支付模式徽章（蓝色=即时，橙色=委托，绿色=A2A）

## 📝 三种模式对比总结

| 维度 | 即时支付 | 委托支付 | 自主支付 |
|-----|---------|---------|---------|
| **用户在场** | 全程在场确认 | 预先授权，后续自动 | 设定边界，全程自主 |
| **IAC凭证** | ❌ 无 | ✅ 有（定向） | ✅ 有（BOUNDED） |
| **执行时机** | 立即执行 | 智能体后续触发 | 智能体自主决策 |
| **资金账户** | 用户主账户 | 用户主账户/可选子账户 | 专属子账户，资金隔离 |
| **交互协议** | 收银台确认 | IAC核验 | HTTP 402 + A2A |
| **决策权** | 用户 | 智能体（受限） | 智能体（高度自主） |
