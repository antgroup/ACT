# ACT 协议演示指南

## 概述

本演示展示了 ACT (Agent Commerce Transactions) 协议中的三种支付模式，清晰地呈现了它们之间的差异和适用场景。

## 三种支付模式

### 1. 即时支付 (Instant Payment)

**核心特点**：
- 用户全程在场，实时确认支付
- 无需签发 IAC（意图授权凭证）
- 使用已绑定的支付标记（PMT-BND）
- 单笔即时交易

**协议组件**：
- `ADD-INT-EAC`：获取购买意图
- `ADD-INT-ISR`：结构化意图表达
- `CID-MER-CAT`：获取商品目录
- `CID-CART-CFM`：购物车确认
- `PSD-PAY-INS`：即时支付流程

**适用场景**：
- 传统电商购物
- 实物商品购买
- 用户在线时的实时交易

**流程**：
```
用户 -> 智能体：帮我买 iPhone
  |
  v
智能体 -> 商户：搜索商品目录
  |
  v
用户 -> 收银台：确认支付
  |
  v
PSP -> 用户：实时扣款成功
```

---

### 2. 委托支付 (Delegated Payment)

**核心特点**：
- 用户预先签发 IAC 授权
- 智能体在额度内代为支付
- 额度限制可控（总额/单笔）
- 智能体无需用户实时介入

**协议组件**：
- `ADD-INT-EAC`：获取委托意图
- `ADD-INT-ISR`：结构化表达（delegation_mode）
- `ADD-IAC-ISS`：签发 IAC 凭证
- `ADD-IAC-LCM`：IAC 生命周期管理
- `PSD-PAY-DEL`：委托支付流程

**适用场景**：
- 自动续费（如手机套餐）
- 智能代买任务
- 授权使用场景

**流程**：
```
用户 -> 智能体：授权代买
  |
  v
智能体 -> PSP：签发 IAC -> 设定额度
  |
  v
[用户离线]
  |
  v
智能体 -> 商户：自主下单
  |
  v
智能体 -> PSP：基于 IAC 发起支付
  |
  v
PSP -> 智能体：核验 IAC -> 扣款成功
```

**类型**：
1. **平台型智能体定向委托**：多租户共享平台智能体，双重身份验证
2. **专属型智能体定向委托**：智能体与用户强绑定，独立身份核验

---

### 3. 自主支付 / A2A 支付 (Autonomous Payment)

**核心特点**：
- 智能体高度自主决策
- 智能体间交易（Agent-to-Agent）
- 基于 A2A 支付协议
- HTTP 402 语义扩展
- 使用专属子账户资金隔离

**协议组件**：
- `ADD-INT-EAC`：获取任务边界
- `ADD-INT-ISR`：结构化表达（delegation_mode: BOUNDED）
- `PSD-AGT-SUB`：智能体子账户
- `CID-PCA-NEG`：支付能力协商
- `PSD-PAY-A2A`：A2A 支付流程

**适用场景**：
- 智能旅游规划
- 复杂任务外包
- 多步骤服务发现与购买

**流程**：
```
用户 -> 买方智能体：设定任务边界（如预算 5000 元出差规划）
  |
  v
买方智能体 -> PSP：开立子账户 -> 充值
  |
  v
[子账户就绪]
  |
  v
买方智能体 -> 卖方智能体：服务发现（机票、酒店等）
  |
  v
卖方智能体 -> 买方智能体：HTTP 402 支付诉求
  |
  v
买方智能体 -> PSP：A2A 支付 (子账户密钥签名)
  |
  v
PSP -> 买方智能体：支付凭证传递
  |
  v
买方智能体 -> 卖方智能体：资源访问授权
```

---

## 三种模式对比

| 维度 | 即时支付 | 委托支付 | 自主支付 |
|------|---------|---------|---------|
| 用户在场 | 全程在场 | 预先授权 | 设定边界 |
| 是否需要 IAC | 否 | 是 | 是 |
| 决策权 | 用户 | 智能体（受限） | 智能体（高度自主） |
| 支付方式 | 用户支付标记 | IAC 核验 | A2A + 子账户 |
| 交互次数 | 单次 | 单次授权 + 多次支付 | 单次边界 + 多次 A2A |
| 资金隔离 | 否 | 否 | 是（子账户） |
| HTTP 状态码 | 200 | 200 | 402 |

## 使用指南

### 启动服务

```bash
cd impl/python
streamlit run ui/app.py
```

### 界面导航

1. **身份选择**：首先选择用户（User）或商户（Merchant）角色
2. **角色切换**：右上角可进行角色切换，数据实时同步
3. **支付模式演示**：用户中心第一 Tab 展示三种支付模式的对比和交互式演示

### 演示操作

#### 即时支付演示
1. 选择"即时支付演示"模式
2. 浏览商品列表
3. 添加商品到购物车
4. 点击"立即结算"完成支付

#### 委托支付演示
1. 选择"委托支付演示"模式
2. 创建 IAC 委托协议（设定总额度和单笔额度）
3. 查看委托状态和剩余额度
4. 选择商品进行委托购买

#### 自主支付演示
1. 选择"自主支付演示"模式
2. 创建自主支付任务（设定总预算）
3. 买方智能体自主执行任务
4. 查看 A2A 交易记录和子账户余额

## ACT 协议核心概念

### IAC (Intent Authorization Credential)

意图授权凭证，是委托支付的核心。IAC 包含：
- 委托人身份
- 智能体身份
- 授权边界（额度、时间、品类）
- 数字签名（PSP 核验）

### 子账户 (Sub-account)

智能体专属子账户，用于资金隔离：
- 独立于用户主账户
- 支持智能体签名
- 降低用户主账户风险

### A2A 支付

Agent-to-Agent 支付协议：
- HTTP 402 Payment Required 语义扩展
- 支付凭证机制
- 智能体身份验证
