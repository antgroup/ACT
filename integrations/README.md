# Integrations

本目录连接 ACT 候选协议与具体运行时或产品，不重定义 Core。

| 目录 | 回答的问题 | 当前状态 |
|---|---|---|
| [`bindings/`](bindings/README.md) | ACT 消息如何由 HTTP 等跨产品运行时承载 | Preview / Non-normative |
| [`profiles/`](profiles/README.md) | 具体产品如何映射 ACT 字段、API、状态与错误 | Preview / Non-normative |

支付宝开户、授权、沙箱和 API 操作以 [AIPay 官网](https://aipay.alipay.com/callpay)及其官方接入文档为事实来源；仓库只保留协议映射和最短接入示例。
