# Glossary

| Term | Meaning |
|---|---|
| ACT | Agentic Commerce Trust Protocol |
| ADD | Authorization & Delegation Domain |
| CID | Commerce Interaction Domain |
| PSD | Payment Services Domain |
| TSD | Trust Services Domain |
| A402 | ACT payment-access component using an HTTP 402 challenge and proof retry |
| IAC | Intent Authorization Credential |
| ISR | Intent Structured Representation |
| L1 / INS | User-present, per-payment identity and authorization confirmation |
| L2 / DEL | Automatic payment for a transaction whose goods, merchant, amount, and limits are explicitly specified |
| L3 / AUP | Autonomous payment within a bounded task, budget, and policy |
| PSP | Payment service provider |
| Payment-Needed | Payment requirement returned with an HTTP 402 response |
| Payment-Proof | Payment evidence submitted when retrying the original request |
| Payment-Validation | Optional validation result returned after proof verification |
