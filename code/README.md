# Code

本目录只承载可运行资产，不定义 ACT 协议或支付宝产品事实。

| 目录 | 用途 | 当前状态 |
|---|---|---|
| [`examples/`](examples/README.md) | 面向开发者的最短接入与本地验证路径 | Preview / Non-normative |
| [`web-client/`](web-client/README.md) | 协议流程展示与脱敏沙箱证据回放 | Demo / Non-normative |

项目尚未发布 SDK，因此不建立空的 `sdk/` 目录。协议语义以 [`specs/`](../specs/README.md) 为准；产品映射和传输绑定以 [`integrations/`](../integrations/README.md) 为准。
